## 1. Scope & Architecture Baseline

This STRIDE analysis evaluates all active subsystems in the repository as of `2026-11-26`:
- **Rust Policy & Crypto Core (`core/`)**: `tier.rs`, `url_policy.rs`, `ingest.rs`, `verify_loop.rs`, `updater.rs`, `ed25519.rs`, `bridge.rs`, `win32.rs`.
- **Python CLI, Agent Core & Sandboxes (`research/`)**: `pai.py`, `shell.py`, `agent_core.py`, `net_guard.py`, `outbound_policy.py`, `ingest.py`, `data_verifier.py`, `capabilities.py`, `sandbox_win32.py`, `sandbox_linux.py`, `sandbox_policy.py`, `verify_loop.py`, `eval_harness.py`, `router.py`, `config.py`, `service_manager.py`, `cloud_ai.py`, `credential_store.py`, `quota_engine.py`, `mcp_client.py`, `automation.py`, `antigravity_driver.py`, `auto_memory.py`, `cowork.py`, `council.py`, `multi_agent.py`, `updater.py`.
- **Desktop Workstation (`desktop/`)**: Tauri 2.0 shell (`desktop/src-tauri/`), web UI (`desktop/ui/`), loopback HTTP bridge (`desktop/bridge_server.py`), `pai_folder_picker.exe`, `apply_pending_update.py`.
- **Packaging & Distribution (`packaging/`, `tools/`)**: native launcher (`packaging/launcher/launcher.c`), payload builder (`build_payload.py`), pin audit (`tools/check_pins.py`), secret scanner (`tools/check_secrets.py`).

Boundary IDs (`B1`–`B8`) map to [TRUST_BOUNDARY_DIAGRAM.md](TRUST_BOUNDARY_DIAGRAM.md); Threat IDs (`T1`–`T35`) map to [THREAT_MODEL.md](THREAT_MODEL.md).
