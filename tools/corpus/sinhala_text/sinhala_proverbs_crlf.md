# සාම්ප්‍රදායික සිංහල ප්‍රස්ථා පිරුළු (Traditional Sinhala Proverbs)

1. ඉඟුරු දී මිරිස් ගත්තා වාගේ.
   - තේරුම: එක අපහසුතාවයකින් මිදෙන්නට ගොස් ඊට වඩා දැඩි අපහසුතාවයකට පත්වීම.

2. අටුව කඩා පුටුව හැදුවා වාගේ.
   - තේරුම: වටිනා ප්‍රධාන දෙයක් විනාශ කර සුළු හෝ තාවකාලික දෙයක් සකස් කර ගැනීම.

3. ගහෙන් වැටුණු මිනිහාට ගොනා ඇන්නා වාගේ.
   - තේරුම: එක් කරදරයකට පත්ව සිටින විට තවත් විපතක් එකතු වීම.

4. දිලිසෙන සියල්ල රන් නොවේ.
   - තේරුම: බාහිරින් ආකර්ෂණීය පෙනුමක් තිබුණද අභ්‍යන්තරය වටිනා එකක් නොවිය හැක.
