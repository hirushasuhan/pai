# core/ — Rust Engine (`pai-core`)

Charter (ADR-004, ADR-011): engine, planner, stateless purge (`zeroize`), network client, URL policy, capability broker, safe ingestion primitives, verify-loop primitives, hardware telemetry.

## Implemented Slices
1. `src/tier.rs` (VS2): Pure hardware budgeting policy mirroring Python `_calculate_budget`.
2. `src/url_policy.rs` (VS2): Pure URL validation and Canonical Blocked CIDR table (RFC 1918, RFC 3927, loopback, multicast, transition IPv6).
3. `src/win32.rs` (VS3): Native Win32 (`kernel32.dll`) telemetry (`GlobalMemoryStatusEx`, `GetSystemTimes`, `GetSystemPowerStatus`) with non-Windows safe stub fallback.
4. `src/ingest.rs` (Phase 2 Slice 1): Pure safe Rust (`#![forbid(unsafe_code)]`) implementation of the string-level safe-ingestion, secret-scanning, terminal/text/header sanitization, and nonce-envelope primitives (`get_ingest_limits`, `is_secret_file`, `is_junk_dir`, `scan_secret_content`, `sanitize_terminal_output`, `sanitize_text_content`, `sanitize_header`, `defang_envelope_markers`, `wrap_untrusted_envelope`).
   - **Slice 1 Scope Boundary**: Filesystem traversal, path/symlink boundary checks, and size/count quota enforcement (`ingest_file`, `ingest_folder`, `assemble_untrusted_context`) remain in Python (`research/ingest.py`) in Slice 1.
5. `src/verify_loop.rs` (Phase 2 Slice 2): Pure safe Rust (`#![forbid(unsafe_code)]`) implementation of the verify-loop trust-boundary primitives:
   - **Tagged RPC Value Codec (`CodecPolicy`, `PaiValue`, `encode_value`, `decode_value`, `decode_envelope_json`)**: Strict RFC 8259 JSON parser (`parse_strict_json` rejecting duplicate object keys, `NaN`/`Infinity` literals, and integers outside `[i64::MIN, i64::MAX]`), strict 2-key envelope (`{"t", "v"}`), recursion depth $\le 32$, collection length $\le 1,000$, total item count $\le 50,000$, duplicate `dict` key and duplicate `set`/`frozenset` element rejection using Python-consistent key equality (`1 == 1.0 == True`, `0 == 0.0 == False`, `-0.0 == 0.0`), canonical `set`/`frozenset` element ordering, and strict padded base64 for `bytes`.
   - **HMAC-SHA256 Verdict Frame Framing & Constant-Time Verification (`format_authenticated_verdict_frame`, `verify_verdict_frame`)**: Pure-Rust SHA-256 + HMAC-SHA256 (`constant_time_eq`), explicit byte caps (`MAX_VERDICT_STREAM_BYTES = 1_048_576`, `MAX_VERDICT_FRAME_BYTES = 262_144`), duplicate JSON key rejection, and full status/nonce/hash/test-ID/count consistency checks.
   - **Canonical Example Assertion Extractor (`extract_example_assertions`)**: Bounded recursive-descent literal expression parser (`MAX_RECURSION_DEPTH = 32`, `MAX_COLLECTION_LENGTH = 1_000`, `MAX_EXTRACTED_STATEMENTS = 50`, `i64` bounds) supporting Unicode identifiers (including Sinhala script), `rb`/`br` bytes literal prefixes, trailing-comma stripping on example lines, and unary parenthesized operands (`-(1)`), generating canonical `assert ...` statements.
   - **Canonical Float Wire Form Parity (`format_python_float`)**: Python `repr(float)` wire form parity with shortest round-trip digits, exponential forms (`e+XX`/`e-XX`) when exponent $< -4$ or $\ge 16$, positional `.0` when $-4 \le \text{exponent} < 16$, and strict alignment between `StrictJson::to_python_canonical_json`, `set`/`frozenset` sort keys, and `serde_json::Value` emission under `arbitrary_precision`.
   - **Slice 2 Scope Boundary**: Subprocess orchestration, AST static analysis (`ast_guard`), test suite assembly (`prepare_test_suite`), and the repair loop remain in Python (`research/verify_loop.py`) in Slice 2.
6. `src/conformance.rs` & `src/main.rs`: Golden vector runner (`--conformance <DIR>`) and panic-isolating (`catch_unwind`) differential fuzz validator (`--differential <FILE>`).

### Design & Safety Guarantees
- **Unsafe Code Policy**: `src/lib.rs` sets `#![deny(unsafe_code)]` at the crate root, and `src/ingest.rs` and `src/verify_loop.rs` enforce `#![forbid(unsafe_code)]`. Only `src/win32.rs` opts in via `#![allow(unsafe_code)]` on `#[cfg(windows)]` for the three `kernel32.dll` FFI calls.
- **Zero Network Crate Dependencies**: Strictly uses `serde` + `serde_json` and standard library types (`std::net`).
- **Conformance & Multi-Seed Differential Verification**: Verified against 200 tier vectors, 87 URL vectors, 113 ingest vectors, and 73 verify-loop vectors, plus widened multi-seed differential fuzzing across reviewer and adversarial seeds (`101`, `202`, `303`, `42`, `555`, `777`, `31337`) with 0 mismatches, 0 panics, and deterministic no-panic property tests in `src/ingest.rs` and `src/verify_loop.rs`.
